"When infrastructure fails,

Lyndhurst, OH · May 2026 · Released to the commons
// WHAT THIS IS
The grid is fragile. We handed control of our communications — our ability to organize, to call for help, to simply speak to our neighbors — to a handful of corporations and a patchwork of infrastructure that was never designed to survive what's coming.

When it fails, most communities will have nothing.

This system is a response to that. A field manual. A prep kit. A framework built from open-source tools, amateur radio tradition, and the simple belief that communities should not need a corporation's permission to talk to each other.

It is not finished. It was never meant to be finished by one person.
// THIS NEEDS BATTLE TESTING
This system was built as a starting point — a skeleton that needs people who've actually been in the field when things broke.

It needs radio operators who know what actually works when repeaters go down. Network engineers who've watched a mesh fail under load. Security researchers who can find the holes before bad actors do. Community organizers who know that the hard part isn't the technology — it's the people. First responders who can tell us what information actually matters in the first 72 hours.

If that's you: this project needs you more than it needs another document.
// THE POINT
Take this. Break it. Improve it. Redistribute it.
The goal is not a perfect manual.
The goal is communities that own their own communications.
No subscription. No terms of service. No kill switch.
Ours.

📡 HOW TO HOST YOUR FILES
Click to expand

OPTION A — PROTON DRIVE Recommended for privacy

  1. Upload each file to Proton Drive
  2. Right-click the file → Share → Create public link
  3. Copy the link and paste it into Custodian Setup above

Proton Drive links deliver a download — visitors will download the file, not view it in browser. This is fine and expected.

OPTION B — NETLIFY Same site, same host

  1. Create a folder on your computer
  2. Put offline-resilience-kit.html in the root, renamed to index.html
  3. Create a downloads/ subfolder
  4. Put all kit files in downloads/
  5. Drag the entire FOLDER (not just the HTML) to app.netlify.com/drop
  6. Your file URLs will be: yoursitename.netlify.app/downloads/field-manual.pdf

This is the cleanest setup — everything lives in one place, no external dependencies.

OPTION C — ANY PUBLIC FILE HOST

Any service that gives you a direct download URL works: Proton Drive, Google Drive (use direct link format), GitHub Releases, Archive.org (free, permanent, anonymous), or your own server.

Internet Archive (archive.org) is free, permanent, requires only an email, and has never taken down community resources. Consider uploading the full kit there for long-term resilience.
