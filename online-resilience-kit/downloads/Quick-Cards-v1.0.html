DESIGN NOTE: Each card is designed to print on a half-sheet (5.5″ × 4.25″) or standard index card. Print double-sided, laminate, and distribute. Card borders are indicated by a dashed-line box on each card. Cut along the dashed border after printing.
PRINTING INSTRUCTIONS
1. Print this document double-sided on standard 8.5″ × 11″ paper (two cards per sheet).
2. Align front and back carefully before cutting along the dashed borders.
3. Laminate each card at 3–5 mil thickness for field durability.
4. Distribute to all team members. Store one set in every go-box.
Tip: Print at 100% scale — do not scale to fit. Use portrait orientation.
Quick-Card 1 — Radio Net Check-In Procedure
QUICK-CARD 1 ▶ FRONT
RADIO NET CHECK-IN

When net control calls: "[Your call sign], go ahead"

YOUR RESPONSE:

  1. State your call sign
  2. State your location (grid square or neighborhood)
  3. State your status: NORMAL  /  TRAFFIC  /  EMERGENCY
  4. Wait for acknowledgment
If EMERGENCY: Say "BREAK BREAK BREAK" + your call sign + nature of emergency. Do not wait for net control to call you.

Quick-Card 3 — Meshtastic Quick Setup
QUICK-CARD 3 ▶ FRONT
MESHTASTIC SETUP IN 5 STEPS
  1. Download Meshtastic app (Android / iOS) or use flasher.meshtastic.org
  2. Flash firmware to device (TTGO T-Beam, Heltec, etc.)
  3. Open app → pair via Bluetooth
  4. Set: Region = US, Channel = LongFast (default)
  5. Set device name → You're on the mesh!

CHANNEL SECURITY

  • Default: No encryption (public)
  • Add PSK: Settings → Channels → Add encryption key
  • Share key only with trusted members
QUICK-CARD 3 ◀ BACK
MESHTASTIC TROUBLESHOOTING
ProblemFix
No connection?Restart device + app
No messages received?Check region setting (must match)
Poor range?Elevate antenna above obstacles
Battery draining fast?Enable router role power settings
Can't pair?Clear Bluetooth cache, re-pair

Quick-Card 4 — SALUTE Report Format
QUICK-CARD 4 ▶ FRONT
SALUTE REPORT — EMERGENCY INFORMATION

Use this format when reporting an incident over radio or in writing.

ElementQuestion to Answer
S — SIZEHow many people / vehicles involved?
A — ACTIVITYWhat is happening?
L — LOCATIONWhere exactly? (address, grid, landmark)
U — UNIT/UNIFORMWho are they? (identifying features)
T — TIMEWhen did you observe this?
E — EQUIPMENTWhat resources / tools are present?
QUICK-CARD 4 ◀ BACK
SAMPLE SALUTE REPORT
S: Approximately 12 people
A: Evacuating a flooded building
L: Corner of Main St and Oak Ave
U: Mix of civilians, 2 in firefighter gear
T: Observed at 14:30 local
E: One boat, several life vests, flashlights

Transmit clearly. Pause between each element. Wait for acknowledgment before proceeding.

Quick-Card 8 — Power Conservation Guide
QUICK-CARD 8 ▶ FRONT
POWER CONSERVATION — EMERGENCY MODE

PRIORITY ORDER (use only what's available)

  1. Essential life-safety communications (always on)
  2. Net check-in radio (scheduled times only)
  3. Mesh node (duty cycle: 50%)
  4. Information gathering / monitoring
  5. Non-essential devices (OFF)

RADIO POWER SAVINGS

  • Transmit only when necessary
  • Use lowest power setting with reliable contact
  • Monitor only between scheduled transmit times
  • Share charging among group members

Quick-Card 10 — Mutual Aid Principles
QUICK-CARD 10 ▶ FRONT
MUTUAL AID — CORE PRINCIPLES
#Principle
1SOLIDARITY, NOT CHARITY — We help each other as equals
2NO GATEKEEPING — Access is not means-tested
3MOST VULNERABLE FIRST — Prioritize those with greatest need
4TRANSPARENT DISTRIBUTION — Account for all shared resources
5NO HIERARCHY IN CRISIS — Anyone can ask for and give help
6DOCUMENT EVERYTHING — Written records protect everyone
7SELF-CARE IS COMMUNITY CARE — Helpers must also rest
QUICK-CARD 10 ◀ BACK
RESOURCE REQUEST PROCESS
  1. State the need clearly and specifically
  2. Verify with the requesting person / household
  3. Check available resources
  4. Fulfill from nearest source
  5. Document: what was given, to whom, when
  6. Replenish stock when possible
NEVER deny based on: identity, ability to pay, relationship to the group, or perceived "worthiness." Access is unconditional.

SETUP & TEARDOWN ORDER

SETUP ORDER

  1. Select elevated, open location
  2. Set up antenna first (before radio)
  3. Connect power source; verify voltage
  4. Power on radio — check frequency
  5. Monitor before transmitting
  6. Check in on local net or calling frequency
  7. Establish and maintain communications log

TEARDOWN

□ Log final entry (time, reason for teardown)

□ Disconnect antenna before moving radio

□ Secure all cables before transport

□ Verify USB kit is packed
