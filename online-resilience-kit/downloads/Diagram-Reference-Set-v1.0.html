THE THREE PILLARS OF COMMUNITY RESILIENCE

"The system rests on three independent, mutually reinforcing pillars. When one fails, the others continue to function. True resilience requires all three."

Each pillar is fully independent. A mesh network outage (power failure, device damage) does not affect radio communications or physical runners. A radio blackout does not stop messages from traveling by foot. Physical disruption of runner routes does not silence radio or mesh. In practice, all three pillars operate simultaneously, reinforcing each other: runners carry messages to mesh node custodians, radio nets relay summaries to the regional network, and visual signals keep households without any electronic equipment informed.

Communities should aim to activate all three pillars before an emergency occurs. The most common failure point is over-reliance on a single system — particularly internet-dependent apps that fail the moment connectivity is lost.

MINIMUM VIABLE NETWORK

Three nodes are the minimum to demonstrate mesh routing around a single failure. Recommended density: one node per 2 km² of coverage area, with each node visible (line of sight preferred) to at least two others. Nodes at elevation — church steeples, water towers, hilltops, rooftops — dramatically extend range and should be prioritized during deployment.

NODE NAMING CONVENTION

Assign alphanumeric IDs (NODE-01, NODE-02 …) in order of installation. Record each node's GPS coordinates, custodian name, and power source in the Node Registry (USB Kit → 05_DATA → Node_Registry.csv). Update whenever a node is added, relocated, or decommissioned.

ANTENNA PLACEMENT

Antenna height is the single most important factor in range. Every doubling of antenna height roughly doubles line-of-sight range. Mount on a mast, fence post, or rooftop bracket. Keep coax cable short (under 2 m if possible) to minimize signal loss.

NO SINGLE POINT OF FAILURE

If a Block Captain is unreachable during an emergency, any household in that cell may step up and take on coordination. Every cell member should know the name and contact of their Household Lead, their Block Captain, and the Cluster Lead. Pre-designate a backup for every role in the tree. Write backup names in the contact list — never rely only on memory.

SELF-SUFFICIENCY PRINCIPLE

Each cell should be able to sustain basic internal communications and welfare checks for a minimum of 72 hours without any upward connection to the cluster or regional network. Design cell resources (water, first aid, information boards) accordingly.

TREE ACTIVATION PROTOCOL

Net Control activates the tree by announcing on the primary calling frequency: "[COMMUNITY NAME] NET — TREE ACTIVATION — PRIORITY [ROUTINE / URGENT / EMERGENCY] — ALL CLUSTER LEADS ACKNOWLEDGE." Each Cluster Lead acknowledges, then immediately begins contacting Cell Captains. The tree should be exercised (tested) at least quarterly with a routine check-in to confirm all contacts are current and reachable.

DUPLICATION AND DISTRIBUTION

Every Block Captain and Cluster Lead should hold a copy of the USB kit. Store one sealed copy in the go-box (Figure 8). Keep a master copy at the community hub, updated at each quarterly exercise. USB drives are inexpensive — err toward over-distribution. A kit that exists only in one location is not a resilience resource.

Notes for Reproduction

All diagrams in this document are designed to be reproduced by any of the following methods — with no special software, equipment, or training required:

  1. Photocopied directly from this document. Each figure is contained within a single page or page spread. Figures may be copied individually and distributed as stand-alone reference sheets. Black-and-white photocopying is fully supported — no color is required for any diagram to be legible and functional.
  2. Hand-drawn onto whiteboards or flip charts for workshop use. All diagrams use standard characters, lines, and box-drawing symbols that can be reproduced with a marker. The ASCII/text art format is deliberately chosen for this purpose. Instructors should practice drawing key figures (especially Figures 1, 2, 5, and 6) before workshops.
  3. Scaled and printed as posters for community hubs. Figures 1, 5, 9 and 10 are particularly suitable for large-format printing and posting at community bulletin boards, fire stations, libraries, and other hubs. Print at A3 (11×17") or larger for readability at a distance.
  4. Transcribed into digital formats for the USB kit. All text in this document is plain Unicode. Figures may be copied into plain text files (.txt), spreadsheets, or any word processor without loss of structure, provided a monospace font (Consolas, Courier New, or equivalent) is used for diagram sections.

INTENTIONAL DESIGN CHOICE

The ASCII and text-art format used throughout this diagram set is intentional — not a limitation. It ensures that every diagram in this set remains fully accessible and reproducible even if all electronic versions are unavailable, all printers are offline, and all software is inaccessible. A diagram that can only be read on a screen is not a resilience resource. A diagram that can be drawn from memory with a pencil is.

Adapting Diagrams for Your Community

Every blank field in this document — underscores, empty table cells, placeholder labels — is an invitation to customize. Before storing this document in your USB kit or distributing printed copies, fill in the following:

  • Figure 2: Replace NODE-01 through NODE-08 with your actual node IDs, locations, and custodian names. Mark failed or planned-but-not-yet-installed nodes accordingly.
  • Figure 5: Replace CLUSTER A / CLUSTER B and CELL 1–6 with your geographic cluster and cell names. Add the name and contact of each Block Captain and Cluster Lead.
  • Figure 6: Fill in the name and call sign of your Net Control operator and all Cluster Leads, Cell Captains, and Household Leads. Add backup contacts for each position.
  • Figure 9: If your community agrees to modify any visual signal meanings, note the change clearly on every copy and record the date of the revision.
  • Figure 10: Draw or paste in your actual neighborhood street map as the base layer. Use the route and runner tables to record all assignments. Store a filled-in copy in USB Kit folders 02_MAPS and 05_DATA.

Store the completed, community-specific version of this document in your USB kit alongside the blank master. Distribute printed copies to every Block Captain and Cluster Lead. Review and update at every quarterly exercise.

Version Control

When you make community-specific edits, update the version number and date in the document title and on the cover page. Use the format: v1.0-[COMMUNITY]-[YYYYMM] (e.g., v1.0-NORTHSIDE-202606). This makes it easy to identify which version of the document a given copy belongs to, and whether it is current.
